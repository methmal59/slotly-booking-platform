# Assets

Demo recordings and screenshots used by the main README.

The WhatsApp clips are scripted product demos: the conversations are rendered
frame-by-frame from the bot's real production reply formats (summary blocks,
confirmation messages, interactive lists and buttons are verbatim), against a
fictional demo salon. To try the real bot live, message the number in the main
README.

- `bot-booking.gif` — full English booking: greeting buttons → service picker → day/time pickers → summary → confirmation
- `bot-revision.gif` — mid-flow revision ("actually make it 3:30pm") re-checked and re-summarised
- `bot-honesty.gif` — closing-time honesty: explains why a slot can't fit instead of claiming it was taken
- `bot-booking-sinhala.gif` — the same flow in casual spoken Sinhala
- `staff-notification.png` — WhatsApp template notification a branch manager receives on a new booking
- `dashboard.png` — business dashboard (revenue, top services, today's schedule) — real app, demo data
- `bookings.png` — bookings view with a pending approval request — real app, demo data
- `storefront.png` — public tenant storefront — real app, demo data
